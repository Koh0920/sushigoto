# 寿司GoTo

「流れる前に、捌け！」

ポモドーロテクニックと回転寿司のゲーミフィケーションを組み合わせた、TODO・時間管理アプリです。

## 主な機能

- 仕込み → 実食 → 精算のフェーズ進行
- お皿ごとの自動ポモドーロタイマー
- 制限時間超過時の鮮度低下ペナルティ
- 回転寿司風の待機タスクレーン
- メモ・リンク・資料のタスクアセット管理
- 実データによる日次精算、月間ヒートマップ、自己ベスト番付
- JSONファイルからのタスク取り込み
- LocalStorageによるデータ永続化

## 起動方法

### Ato

```bash
ato run .
```

### 静的サーバー

```bash
python3 -m http.server 8080
```

その後、`http://127.0.0.1:8080/` を開いてください。

## JSON取り込み形式

配列、または `tasks` 配列を持つオブジェクトを取り込めます。

```json
{
  "tasks": [
    {
      "title": "見積書を確認して返信",
      "plate": 2,
      "items": [
        {
          "type": "memo",
          "title": "確認事項",
          "content": "金額と納期を確認する"
        }
      ]
    }
  ]
}
```

`plate` は `1`（並皿・5分）、`2`（上皿・15分）、`3`（特上皿・25分）です。
